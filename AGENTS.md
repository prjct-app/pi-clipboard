# Agent instructions

Read `CONTRIBUTING.md` before changes. Work on a feature branch based on `main` and deliver changes through a pull request using `.github/pull_request_template.md`.

Use English for code, documentation, tests, issues, and pull requests. Use Pi 0.85.1 public extension and TUI interfaces. Keep clipboard image data local, accept only Pi-owned temporary clipboard attachments, reject symbolic links, and keep tests offline with temporary files.

Never push, open or merge a pull request, publish, or deploy without explicit user authorization.
